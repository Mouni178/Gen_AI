# Semantic Search Engine using FAISS

## Overview
This project implements a semantic search engine that understands the meaning of user queries and retrieves relevant documents using vector similarity.

## Objectives
- Understand semantic search.
- Generate text embeddings.
- Store and search vector representations.
- Retrieve the most relevant documents.
- Explore similarity scoring.

## Technologies Used
- Python
- Sentence Transformers
- FAISS
- NumPy

## Model Used
`sentence-transformers/all-MiniLM-L6-v2`

## Key Concepts
- Semantic Search
- Text Embeddings
- Vector Search
- FAISS Indexing
- Cosine Similarity
- Top-K Retrieval

## Applications
- Search Engines
- Document Retrieval
- Question Answering
- Chatbots
- Retrieval-Augmented Generation (RAG)

## Learning Outcome
Learned how to build a semantic search system using vector embeddings and FAISS to retrieve relevant information based on meaning rather than exact keyword matches.
