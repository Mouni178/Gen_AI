# Text Embeddings

## Overview
This project explores how machines convert human language into numerical representations called **text embeddings**.

## Objectives
- Understand text embeddings.
- Convert sentences into numerical vectors.
- Explore embedding dimensions.
- Understand semantic representation of text.

## Technologies Used
- Python
- Sentence Transformers
- NumPy
- Scikit-learn

## Model Used
`sentence-transformers/all-MiniLM-L6-v2`

- Generates 384-dimensional sentence embeddings.
- Captures semantic information from text.

## Key Concepts
- Text Embeddings
- Vector Representation
- Tokenization
- Semantic Similarity
- Embedding Dimensions

## Applications
- Semantic Search
- Chatbots
- Recommendation Systems
- Document Search
- Retrieval-Augmented Generation (RAG)

## Learning Outcome
Learned how text is transformed into numerical vectors and how embeddings form the foundation of semantic search and modern AI applications.
